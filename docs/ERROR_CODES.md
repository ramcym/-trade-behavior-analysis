# Error Codes

Use error codes to make repeated mistakes visible and countable.

| Code | Name | Description |
| --- | --- | --- |
| E01 | 杂毛交易 | 买入非核心、跟风或冷门标的。 |
| E02 | 连续盈利后降低标准 | 连续盈利后放松筛选、放大仓位或随手买。 |
| E03 | 顶背离追点火 | 在顶背离或高位衰竭时追点火。 |
| E04 | 第一选择没买，买第二选择 | 错过最强标的后买入替代标的。 |
| E05 | 大盘不配合仍买入 | 指数环境不支持时强行开仓。 |
| E06 | 板块不配合仍买入 | 板块走弱或分歧未确认时买入。 |
| E07 | 指数回流预期覆盖个股负面信号 | 用指数或板块预期忽略个股风险。 |
| E08 | 亏损后不止损，幻想修复 | 亏损扩大后没有按计划止损。 |
| E09 | 把杂毛当龙头格局 | 给非核心标的过高持仓预期。 |
| E10 | 买卖逻辑混乱 | 系统 A 买入，系统 B 卖出，买卖逻辑不一致。 |
